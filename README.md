
# Airline Operation Analysis | Power BI

## Project Overview
An interactive, two-page Power BI dashboard designed to analyze airline operational performance, flight delays, cancellations, and on-time performance.

## Key Features
- **Flight Overview:** Total, operated, delayed, cancelled, diverted, and on-time flights.
- **Performance Trends:** Monthly flight volumes and top airlines by total flights.
- **Delay Analysis:** Average departure and arrival delays by weekday and hour.
- **Cancellation Analysis:** Breakdown of cancellations by reason.
- **Interactive Exploration:** Dynamic KPI cards, slicers, and a decomposition tree for analyzing flight performance.

## Dashboard Pages
1. **Summary Dashboard** – Flight KPIs, monthly trends, weekday analysis, and airline comparisons.
2. **Operational Analysis** – Cancellation reasons, delay patterns, and flight decomposition analysis.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Objective
To transform airline operational data into meaningful insights that support performance monitoring and data-driven decision-making.
